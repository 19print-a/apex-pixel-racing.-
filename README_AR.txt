موقع Apex Pixel Racing
======================

محتويات الحزمة:
- index.html : صفحة الموقع.
- game.apk : ملف اللعبة المرفق.
- download.php : يرفع عداد التحميل عند طلب ملف اللعبة.
- stats.php : يعرض الإحصائيات.
- like.php : يسجل إعجاباً واحداً لكل متصفح (باستخدام Cookie).
- common.php و data.json : تخزين العدادات على الخادم.

طريقة النشر:
1) ارفع جميع الملفات كما هي إلى مجلد واحد في استضافة ويب تدعم PHP 7.4 أو أحدث.
2) تأكد أن PHP يستطيع الكتابة في data.json أو في مجلد الموقع. قد تحتاج إلى صلاحية كتابة مناسبة لملف data.json.
3) افتح رابط index.html.
4) جرّب زر التحميل وزر الإعجاب. الأرقام مشتركة بين زوار الموقع لأنها محفوظة على الخادم.

مهم بخصوص الأرقام الحقيقية:
- عداد التحميل يسجل كل طلب ناجح إلى download.php بعد التأكد من وجود ملف APK وفتحه. هذا يقيس مرات بدء تنزيل الملف، وليس عمليات التثبيت المكتملة أو الأشخاص الفريدين.
- عداد الإعجاب يسجل إعجاباً واحداً لكل متصفح ما دام ملف تعريف الارتباط موجوداً. حذف بيانات المتصفح أو استخدام جهاز/متصفح آخر قد يسمح بإعجاب جديد.
- الأرقام تبدأ من صفر عند النشر، وتبقى محفوظة في data.json على نفس الاستضافة. لا يعمل نظام العدادات على فتح index.html محلياً أو على استضافة صفحات ثابتة فقط مثل GitHub Pages؛ يلزم خادم يدعم PHP.
- لا ترفع ملف data.json إلى مكان عام إذا كانت الاستضافة تسمح بحمايته؛ يفضّل وضعه خارج مجلد الويب أو منع الوصول المباشر إليه عبر إعدادات الاستضافة.
